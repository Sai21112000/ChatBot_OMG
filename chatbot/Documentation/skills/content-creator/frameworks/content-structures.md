# Content Structures

- **Problem -> mechanism -> solution -> action:** practical explainers.
- **Claim -> evidence -> implication:** analytical or opinion writing.
- **Before -> friction -> after:** experience-based stories.
- **Concept -> architecture -> implementation -> failure modes:** technical guides.
- **Myth -> why it persists -> correction -> application:** misconception correction.

Choose the structure that matches the reader's job, not the one that is easiest to generate.
