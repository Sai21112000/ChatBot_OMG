# Technical Writing Workflow

## Objective

Help a defined technical reader understand and safely apply a concept, system, or procedure.

## Process

1. State reader, prerequisites, environment, and outcome.
2. Give a correct mental model before implementation detail.
3. Explain architecture, interfaces, data flow, failure modes, security boundaries, observability, and trade-offs as relevant.
4. Include minimal, runnable, appropriately scoped examples; distinguish illustrative pseudocode from production code.
5. Validate terminology and version-sensitive behavior against authoritative documentation.
6. Include limits, common errors, and a practical next step.

Use `frameworks/technical-writing.md` and `templates/technical-article.md`.
