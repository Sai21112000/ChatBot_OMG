# Blog Workflow

## Objective

Produce a durable, search-aware educational article that answers a real reader need with enough depth to be useful.

## Process

1. Determine search intent: informational, comparative, transactional, navigational, or problem-solving.
2. State the direct answer early, then develop context, concepts, examples, trade-offs, and next steps.
3. Map the landscape: competing pages, common coverage, missing questions, and differentiators.
4. Build an outline with descriptive H2/H3 headings that reflect reader questions.
5. Support factual claims and add examples, implementation guidance, and limits.
6. Optimize title, intro, headings, internal-link opportunities, metadata suggestion, and FAQ only if they add value.

## Rules

Never pad to a word count. Write for task completion and understanding; use `templates/blog.md`.
