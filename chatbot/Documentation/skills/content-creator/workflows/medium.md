# Medium Workflow

## Objective

Write a reflective, deeply explained article that rewards sustained reading.

## Native sequence

Context -> central argument -> evidence and reasoning -> examples -> implications -> resonant close.

## Rules

Start with a vivid problem, surprising observation, or precise premise. Use narrative only where it advances the argument. Maintain intellectual honesty, explain jargon at first use, and finish with an implication rather than a generic summary. Use `templates/medium.md`.
