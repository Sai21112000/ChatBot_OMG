# Repurposing Workflow

## Input extraction

Identify the canonical thesis, evidence, examples, audience, objections, and practical takeaways. Preserve factual accuracy and source attribution.

## Transform

Create a separate platform brief for each requested output. Rebuild the hook, sequencing, depth, format, and CTA for its native reader behavior; do not merely shorten or expand the master piece.

## Output

For each asset, state its goal, native angle, and final draft. Flag claims that need re-verification because the new format changes context or publication timing.
