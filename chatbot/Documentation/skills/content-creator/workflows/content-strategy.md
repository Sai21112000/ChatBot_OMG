# Content Strategy Workflow

## Diagnose

Classify topic, desired reader action, funnel role, platform, audience sophistication, author credibility, constraints, and publication shelf life.

## Build the brief

Write a one-sentence content thesis: "For [audience], explain/argue [idea] so they can [outcome], using [distinct angle]."

Choose one primary intent: educate, persuade, build authority, start discussion, generate leads, entertain, document, or retain a relationship. Do not optimize equally for all of them.

## Choose the angle

Prioritize an angle that is credible for the author and useful for the reader: contrarian correction, field lesson, failure mode, implementation guide, decision framework, comparison, myth-versus-reality, or trend interpretation.

## Critic pass

Audit hook, clarity, specificity, evidence, logical progression, redundancy, voice, platform fit, and CTA. Give actionable revisions, then produce a revised version only after resolving material weaknesses.

## Analysis mode

When analyzing an existing piece, report topic, audience, intent, angle, structure, hook mechanism, emotional progression, information mix, style signals, evidence quality, strengths, weaknesses, and transferable lessons. Describe patterns; never imitate distinctive phrasing.
