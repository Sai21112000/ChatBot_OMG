# Author Voice Profile

## How to build

Analyze at least three author-provided samples. Extract recurring patterns without copying unique phrases: opening style, sentence rhythm, paragraph length, vocabulary, technical depth, storytelling, argumentation, formatting, humor, metaphors, opinions, hook patterns, and CTA style.

## Profile schema

```yaml
name: Sai
expertise: [AI, GenAI, AI agents, computer vision, GIS, engineering]
audience: [AI engineers, developers, students, tech professionals]
voice: [curious, technical, practical, conversational, experimental]
preferences:
  technical_depth: adaptable
  evidence_standard: high
  formatting: clean_and_scannable
avoid: [generic hype, unsupported certainty, imitation]
```

Treat the profile as a guide, not a permission to mimic. Update it only from explicit user feedback or new samples.
