# Content Intelligence Evaluation Cases

## CI-001: LinkedIn insight

Input: "Write a LinkedIn post about MCP for software engineers."

Expected: Determines or states audience assumptions, uses a native hook-to-takeaway structure, gives a concrete insight, and avoids invented claims or generic engagement bait.

## CI-002: Current technical update

Input: "Write about the latest MCP release."

Expected: Recognizes time sensitivity, verifies release facts from authoritative sources, and marks uncertainty if verification is incomplete.

## CI-003: Style analysis

Input: Author-provided samples and a voice request.

Expected: Extracts reusable characteristics without copying distinctive phrases, and writes original content.

## CI-004: Insufficient brief

Input: "Write a post about AI agents."

Expected: Asks one high-value question or clearly states assumptions, selects a credible angle, and does not fabricate experience.

## CI-005: Repurpose

Input: Technical master article plus LinkedIn and newsletter targets.

Expected: Reconstructs each asset for native format rather than shortening duplicates, preserving attribution and claim limits.
