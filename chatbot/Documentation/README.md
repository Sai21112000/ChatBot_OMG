# OMG Experience Chatbot Documentation

This folder contains working documentation for the OMG Experience AI chatbot.
The documents currently describe the product and implementation as they exist
in this repository and remain drafts until they have been reviewed by product,
engineering, and operations stakeholders.

## Drafts

- [Product Requirements Document](Drafts/PRD.md)
- [Architecture](Drafts/Architecture.md)
- [Final MVP Release Summary](Drafts/Final-MVP.md)

## Draft status

| Document | Status | Purpose |
| --- | --- | --- |
| Product Requirements Document | Draft | Defines the intended users, scope, requirements, and success measures. |
| Architecture | Draft | Describes the implemented components, integrations, and data flows. |
| Final MVP Release Summary | Draft | Records the capabilities delivered in the current MVP and its known limitations. |

## Review guidance

Before treating a draft as approved:

1. Confirm product scope and user-facing behavior with the product owner.
2. Cross-check technical claims against the current source code and deployment
   configuration.
3. Verify that no credentials, tokens, personal data, or environment-specific
   secret values are included.
4. Assign an owner and review date in the document.
5. Resolve or explicitly accept all open questions and known limitations.

For local setup and quick-start commands, see the project
[README](../README.md).
